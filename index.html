구간별 판정

계산 기준. 도로거리 = 직선거리 × 도로계수, 시내 구간(4km 미만)과 국도 구간 평균속도를 따로 적용하고 학교마다 하차·검수 시간을 더합니다. 계수와 속도는 IoT 설정에서 바꿀 수 있으며, 실제 운행 GPS 기록이 쌓이면 학교별 실측값으로 대체됩니다. 중계거점을 켜면 간선 차량이 미리 물량을 옮겨 둔 것으로 보고 거점에서 첫 구간을 계산합니다.

홍천군 표준 식자재

표준식재료 파일 94,992개 품목을 검색하고, 센터가 사용 여부·계약단가·최소발주량·비고를 관리합니다. 센터에서 바꾼 내용은 공유 DB에 저장되어 같은 화면을 여는 담당자 모두에게 바로 반영됩니다.

DB 연결 확인 중
저장 위치. 원본 표준식재료 목록은 페이지와 함께 게시된 읽기 전용 자료이고, 센터가 정한 사용 여부·단가·비고와 센터 등록 품목, 학교별 발주 품목은 이 페이지의 공유 DB에 저장됩니다. 원본 파일을 새로 받으면 목록만 교체하고 센터 관리 내용은 상품코드 기준으로 그대로 이어집니다.

배송 분석

학교별 배송 소요시간, 하차 때 문 열림으로 생긴 적재함 온도 상승 폭과 회복 시간, 30분 기준 준수율을 봅니다. 과거 20일은 시뮬레이션 기록이고 오늘 운행분이 실시간으로 더해집니다.

학교 이동 순서

입·출고 관리

공급업체 출고 → 센터 입고(검수) → 센터 출고(학교별 상차) → 학교 인수 순서로 처리합니다. 공급업체는 출고수량·결품 사유를 입력해 출고를 확정하고, 센터는 입고수량·불량을 검수한 뒤 그 수량을 코스 순서대로 학교에 배정해 상차합니다. 학교 인수는 기사 앱 배송 기록과 연결됩니다.

자동 수집에 대해. 이 페이지는 보안 정책상 umji 사이트에 직접 접속하거나 로그인할 수 없습니다. 지금은 내려받은 파일을 올리는 방식이고, 매일 자동으로 받으려면 umji 연계 API(또는 센터 서버의 정기 수집)가 필요합니다. 연계 규격을 받으면 같은 저장 구조로 바로 연결할 수 있습니다.

기사 계정 관리

배송 기사는 센터가 발급한 아이디·비밀번호로 기사 앱에 로그인합니다. 센터는 기사별 계정과 코스를 관리하고, 오늘 운행 진행을 실시간으로 봅니다.

기사 프로필

이름·아이디·코스는 바로 저장 · 비밀번호는 기사별로 설정

기사 앱 쓰는 법

1. 표에서 기사별 로그인 아이디와 비밀번호를 정합니다.
2. 기사는 휴대폰에서 링크를 열고 "기사 앱"을 누릅니다. 주소 끝에 #driver를 붙이면 바로 기사 화면이 열립니다.
3. 받은 아이디·비밀번호로 로그인하면 본인 코스와 학교 순서가 나옵니다. 5번 틀리면 5분간 잠깁니다.
4. 운행 시작·도착·인수 완료·검수 체크·메모가 공유 DB에 저장되어 이 표의 "오늘 운행"에 바로 나타납니다.
