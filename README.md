# 강원 먹거리 이음 · 홍천 학교급식 스마트 배송

홍천 45개 학교 급식 식자재의 배송·온도·위치를 한 화면에서 관리하는 시연용 관제 웹앱입니다.

- `index.html` — 광역 대시보드, 학교급식 배송, GIS 배송 코스(30분 원칙), 냉장차 관제, 기사 앱(`#driver`)
- `img/` — Sentinel-2 cloudless 2024 위성 영상 (EOX IT Services GmbH, CC BY 4.0)
- `data/std-food.gz.b64.txt` — 홍천 표준식재료 목록

정적 사이트로, Vercel 등에 그대로 배포됩니다. 독립 웹사이트에서는 공유 DB 없이 시연 모드로 동작합니다.

## 공유 DB 서버 (/api)

- `api/auth.js`, `api/db.js`, `lib/` — Vercel 서버리스 함수. 저장소는 Upstash Redis(Vercel Storage 연동, `KV_REST_API_URL`/`KV_REST_API_TOKEN`).
- 역할별 권한은 `lib/policy.js`에서 서버가 판단합니다.
  - 센터 관리자: 전체 읽기·쓰기 (최초 1회 화면 상단 '센터 로그인'에서 비밀번호 설정)
  - 공급업체: 자기 업체 출고 문서만, 출고확정 이후·센터 입고(검수) 항목은 변경 불가
  - 기사: 자기 운행·자기 차량 단말 명령 응답·센서값만
- 저장소가 연결되지 않았거나 로그인하지 않으면 사이트는 기존처럼 이 브라우저 안 시연 모드로 동작합니다.
