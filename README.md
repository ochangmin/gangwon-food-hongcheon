# 강원 먹거리 이음 — 학교급식 수발주 플랫폼

강원특별자치도 시군 학교급식지원센터가 함께 쓰는 수발주 플랫폼입니다. umji(강원 먹거리 통합운영시스템)와 병행 운영하면서 단계적으로 대체하는 것을 목표로 합니다.

- **스택**: Next.js 15 (App Router, 서버 액션) · Supabase (Postgres, Auth, RLS) · Vercel
- **사용자**: 도 관리자 · 센터 관리자 · 학교 영양교사 · 공급업체
- **현재 단계**: 1차 개발본. DB 업무 흐름은 테스트 42건 통과(PGlite·실제 Postgres 16), 웹은 빌드·타입검사 통과. 실제 Supabase 프로젝트에 연결한 화면 테스트는 아직 하지 않았습니다.

## 업무 흐름

```
학교 주간 주문 (작성중 → 제출)
   ↓ 센터 주문확정 ─────────────→ 공급업체별 발주 자동 생성·누적
   ↓                               ↓ 업체: 납품 가능 수량 회신
센터 입고확정 (실입고 수량·창고) → 로트번호 부여 (센터코드-입고일-상품코드)
   ↓ 학교별 출고확정 → 거래명세서 (ST+납품일-학교코드)
   ↓ 배송코스 출발·도착  /  학교 검수확인
배송완료 → 클레임 접수 시 납품 이력에서 로트 자동 연결
```

확정 이후의 상태 변경은 DB 함수로만 가능하고, 테이블을 직접 수정하면 트리거가 막습니다. 단가는 납품일 기준 `item_prices`에서 자동 적용되므로 학교가 바꿀 수 없습니다.

## 권한 (RLS)

| 역할 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 도 관리자 | 모든 센터 | 센터 등록, 센터 관리자 계정 발급, 모든 센터 업무 |
| 센터 관리자 | 자기 센터 전체 | 확정·발주·입고·출고·배송·클레임 처리, 기준정보, 학교·업체 계정 발급 |
| 학교 | 자기 학교 주문·출고·클레임, 납품받은 로트 | 주문 작성·제출(납품일 전날까지), 검수확인, 클레임 접수 |
| 공급업체 | 자기 발주와 로트 | 발주 수량 회신 |

## 폴더

```
supabase/migrations/   0001 스키마 · 0002 RLS · 0003 업무 함수 · 0004 umji 연계
supabase/seed.sql      예시 기준정보 (홍천·춘천 센터)
supabase/tests/        DB 통합 테스트
app/center/            센터 화면 (현황, 주문확정, 발주·입고, 출고·거래명세, 배송, 로트, 클레임, 기준정보, 계정, umji 연계)
app/school/            학교 화면 (주간 주문, 납품·검수, 클레임)
app/supplier/          공급업체 화면 (발주 확인, 로트 이력)
app/province/          도 통합 현황
app/api/umji/ingest/   umji 수집 API
```

## 설치

1. Supabase 프로젝트를 만들고 `supabase/migrations`의 SQL을 순서대로 실행합니다 (Supabase CLI: `supabase db push`).
2. 데모가 필요하면 `supabase/seed.sql`을 실행하고 데모 계정을 만듭니다.
   ```
   DEMO_PASSWORD=10자이상비밀번호 npm run seed:users
   ```
   계정: province@ · hongcheon@ · chuncheon@ · s101@ · p01@ `demo.eum`
3. `.env.example`을 `.env.local`로 복사해 값을 채웁니다.
4. `npm install && npm run dev`
5. 배포: Vercel에 저장소를 연결하고 같은 환경변수를 등록한 뒤 도메인(급식.shop)을 연결합니다.

## umji 병행 운영

umji 출고 데이터를 이음으로 가져오는 방법은 두 가지입니다.

- **화면 수집 스크립트**: umji 출고처리(SA020240) 화면에서 조회한 뒤 센터의 「umji 연계」 화면에 있는 스크립트를 실행하면, 브라우저에 있는 출고 라인(dsInv)을 `/api/umji/ingest`로 보냅니다. 토큰은 `UMJI_INGEST_TOKENS`에 `센터코드:토큰` 형식으로 등록합니다.
- **JSON 붙여넣기**: umji 컬럼명 그대로의 JSON 배열을 붙여넣습니다.

같은 행(INV_SEQ-INV_SERL)을 다시 보내도 중복되지 않고 갱신됩니다. 처음 보는 학교·상품·공급업체는 `umji:번호` 연계 표시와 함께 자동 등록됩니다. umji 데이터 자동 수집은 강원도·공급사(코이션)와 연계 범위를 협의한 뒤 운영에 적용하세요.
